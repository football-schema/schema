Football Schema v0.0.1

A canonical, machine-readable model of association football in JSON-LD — competitions, seasons, clubs, matches and league tables, with the Premier League as the reference competition. Record what happened on the pitch; derive the score, the result and the table.

The core, match and table modules as a UML class diagram — generated from the schema, so it never drifts. Filled diamonds are composition, hollow triangles generalization, open arrows association; /name fields are derived (computed, not stored). Italic, dashed boxes are abstract.

Matches store only events; the score, result, minutes played and every number in the table are derived from them, so a scoreline can never disagree with its goals. tools/model.js implements the derivations; npm test checks the schema, the diagram and the examples. Independent community project; not affiliated with the Premier League.
